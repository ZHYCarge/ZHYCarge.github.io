将“小龙虾”装到绿联NAS中

发表于 2026-03-13 分类于 思源笔记 阅读次数： Waline： 本文字数： 1.1k 阅读时长 ≈ 4 分钟

前言

随着 OpenClaw 的爆火，各个云平台及各家服务商店都推出了关于 OpenClaw 的安装教程，绿联 NAS 也在应用商店上架了一键部署的应用软件，同时与 Minimax 联合，提供了一个月免费 api 使用，因此部署一下做个 QQ 机器人来薅个羊毛。

‍

版本说明

  • 绿联 NAS 系统版本：1.13.1.0105
  • Docker 工具：1.13.1.0004（需要保证大于等于这个版本才能进行使用）
  • OpenClaw：1.0.0.0013

‍

部署

配置 QQ 机器人

  1. 注册 QQ 开放平台账户

    通过访问链接 QQ 开放平台进行申请/注册账户。如果出现下图这个 龙虾专用入口，如果你只是自己使用，不想放在好友群里，点击这个直接扫码登录获取 id 和密钥信息即可，如果想要将你的小龙虾分享到群聊，则需要进行注册操作（好像现阶段个人用户也不能进行群聊的邀请）。

  2. 通过输入邮箱号、密码进行注册，会往邮箱里发送一个邮件，点开之后需要继续填写相关信息用于腾讯实名。此处请注意，超级管理员手机号要和 QQ 号的手机号绑定是一致的（试了下小号扫码绑定会出现无法使用的情况，感觉实名也需要一致）

  3. 后续主体信息根据实际情况进行操作，输入信息，人脸认证，成功之后会返回：

  4. 之后点击到 机器人​→创建机器人，输入好名称、头像以及描述点击创建即可

  5. 点击进去选择左侧的 开发管理​，找到 AppID(机器人ID) ​与 AppSercert(机器人密钥)，将其进行保存

  6. 在后面的 IP 白名单中输入自己家里的 IP 地址，如果不知道可以通过 myip.ipip.net 来进行获取。

  7. 之后点击左侧的沙箱配置，点击右侧二维码即可扫码添加 AI 小助手，至此 QQ 机器人部分配置完成，之后进行 OpenClaw 的后端配置。

‍

绿联云中安装配置 OpenClaw

  1. 应用安装

    在应用中心找到 OpenClaw 并进行安装，配置好存储路径和设置一个具有高强度的网关令牌，点击知晓安全风险之后便可以进行安装。

  2. 安装完成之后桌面上就会出现 OpenClaw ​的快捷启动方式，点击就可以进入后台进行访问。（出现断开与网关的连接是正确的，需要你额外输入之前设置的网关令牌才能进行访问，为了安全）

    当然，如果你配置过绿联云有关防火墙部分，需要在防火墙允许 18789 ​与 18790 ​这两个默认端口（就确实很离谱，绿联云大部分教程都不会提及 Docker 需要的端口要在防火墙中进行放行，可能是默认会用到防火墙的人能了解这个事情？）

  3. 点击左侧的 概览​/Overview​，在 网关令牌​/Gateway Token ​中输入刚才设置的网关令牌信息，点击连接之后就能够在右侧状态信息中看到状态是正常的：

    同时，在刚才配置的网关令牌部分也能切换语言，换成简体中文。

  4. 在左侧找到 频道 ​按钮，点击进去找到 QQ bot，发现出现如下信息：

    因此用以下方式进行配置：

    在绿联云 APP 中依次点击：Docker​→项目​→openclaw（点这个名字）​→openclaw-gateway-1（点这个名字）​→终端​→新增​→确定

    在进入的终端中输入以下命令：（终端粘贴用 Shift​+Insert）

    ​​openclaw channels add --channel qqbot --token "你的APPID:你的AppSercert"

    举例：openclaw channels add --channel qqbot --token "195288554:oasdiufgsduifgsdugfsd"

    当出现 Added QQ Bot account "default". ​即代表配置完成。再查看 QQ bot，会发现变成这样。
